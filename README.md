# Simple Calculator

A clean, responsive calculator built with **vanilla HTML, CSS, and JavaScript**—no frameworks, dependencies, or build step required.

> Open the page and start calculating. Use the on-screen buttons or your keyboard.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input, sign toggle, and percentage
- Clear and backspace controls
- Keyboard support
- Responsive layout with accessible button labels and live display updates
- Handles division by zero and invalid results with a friendly `Error` state

## Try it locally

No installation is needed. Clone or download the repository, then open `index.html` in a browser.

```bash
git clone https://github.com/omegas-vireo4j/improved-meme.git
cd improved-meme
```

Open `index.html` directly, or serve the project locally:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` | Enter a decimal point |
| `+`, `-`, `*`, `/` | Choose an operation |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete the last character |
| `Escape` | Clear the calculator |
